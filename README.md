Archivos publicados de la app del celular para iPhone y navegadores. Se generan desde el repositorio privado `revision-flota` (`movil/www`, después de `npm run build`). No contiene datos ni llaves.

Abrir en Safari: https://tzeind.github.io/revision-flota-app/ y elegir Compartir › Agregar a pantalla de inicio.
